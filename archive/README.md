# Archive: where the raw material lives

The playbooks are the distilled version. This folder (and the Drive backup) is the raw
material, for when a detail isn't in a playbook. Grep it.

## In this repo

| Path | What |
|---|---|
| `conversations/comics-production/` | Text exports of the comic production chats, Aug to Oct 2026 (EP001 to EP005, prompt engineering, shorts) |
| `conversations/comics-scripts/` | Comic script writing and YouTube channel strategy chats |
| `conversations/portfolio-career/` | Portfolio builds (pixel site, cat), case studies, assessments, resume, studio plugin research |
| `conversations/job-automation/` | Building the job-hunt bot (secrets redacted) |
| `artifacts/` | Saved copies of claude.ai artifacts from the old account: comic series script page, Panel Sheet, The Nod, The Phrasebook, Three Lenses, YouTube Format Slate, Cat v2 in Motion, Job Hunt Workflow. Open `index.html` in a browser |
| `../tools/comics-video/` | The comic Remotion source and the Python build scripts (keying, ambience, AI mark, audio timelines) |

Conversation files are named `<last-active-date>-<session-id>.md`. Several are continuations of each
other; each one opens with a summary of the session before it. Tool results are truncated to ~350 chars.

**Left out on purpose:** Tetriz/Epifi work chats (launch video, DORA video, website, quiz app), manager
and work-context chats, daily summaries, off-topic chats. The reusable lessons from the Tetriz video and
website work ARE kept, in `playbooks/video-production.md`, `playbooks/design-taste.md` and `lessons/`.

Conversations before mid-August 2026 were not stored locally (Claude Code cleans old sessions). That
earlier work (DORA video, launch storyboard, website feature pages) survives only through `memory/`.
