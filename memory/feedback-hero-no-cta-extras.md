On the Tetriz marketing feature-page heroes, do NOT add anything below the CTA buttons — no proof chips, status dots, badges, or rows like "Measured against the non-AI baseline / DORA split / 15 minutes to first insight". The hero is: eyebrow + headline + lede + CTA buttons ONLY, matching the AI Adoption hero.

**Why:** Sejal has asked to remove the below-CTA chip row multiple times and asked for it to be remembered. A reference/screenshot that happens to show such chips does NOT override this — the standing rule wins over any reference.

**How to apply:** when porting or matching a reference hero, drop any below-CTA chip/badge row and never re-add it, even if the reference shows one. If a reference clearly intends proof points, ask before adding rather than assuming. See [[feedback-no-overlap]].
