Anandhi's feedback on the DORA/Tetriz video storyboard (meeting ~2026-07-09):

1. **Script is the gap, not animation** — "everything is there conceptually, but the script itself isn't there at all." Detail the script before polishing visuals (extends [[feedback-spine-before-script]]).
2. **Three-pillar map** — Tetriz solves 3 things (Coaching / Harness / Context). All three should be visible as a persistent map; emphasize the current one, de-emphasize the others, so the viewer always knows where they are. Alternative: break into section slides.
3. **Each feature = same explanatory template** — "Coaching does X. For the individual it does X, for the org it does Y." Both visually and in VO, consistently for every pillar.
4. **Individual + org impact must both show** — introducing "24/7 coaching" as a concept isn't enough; show how it affects one engineer AND how it propagates to the whole org (e.g., one person changes color, then the grid glows).
5. **Attention hierarchy** — in any frame the viewer must know exactly where to look; currently "focus is in five different places." One thing at a time; when something new arrives, de-emphasize the old.
6. **Before/after must be visually differentiated** — "if this is the bad version and this is the good one, there's simply no visual difference." Show the transition (red→green, fuzzy prompt crossed out → sharp one checked).
7. **Concept explainer for a time-poor CTO** — Apple/App Store analogy: sell 3-4 big features clearly, don't list everything. Not a dashboard demo; layout doesn't need to mimic the product table if it hurts clarity.
8. **Charts must earn their seconds** — chart is fine only if what it indicates is instantly clear; don't spend ~10s on a growing chart just to say "improving."
9. **Captions must be unambiguous** — she couldn't tell if a caption was a title or a result.
10. **Hook approved** — the Frame-1 problem statement ("shipping more with AI, but are you maximizing it?") works: "a good hook to get me inside."

**Why:** The video is for a CTO with no time and no context; anything requiring the viewer to read every line of text fails.
**How to apply:** Detail the script/beats first and align before animating (storyboard = planning stage, "doing is the easier part"). Animate the coaching section first (skip re-animating the AI-native hook) to test if info flows within the timing; if it doesn't fit, either change the approach or extend the duration — Sejal's call to make and flag.
