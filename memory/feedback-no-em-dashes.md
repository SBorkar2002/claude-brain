Never use em dashes (—) in anything I put into a design: page copy, Figma text layers, frame/layer names, labels.

**Why:** Sejal asked for all of them removed from the Instahyre palette/type boards (2026-10-06) and to remember it for the landing page build. Em dashes read as AI-written copy.

**How to apply:** use a colon, comma, full stop, " · " separator, or rewrite the sentence. After every Figma build, run a check that no TEXT node or node name contains "—" before presenting. Applies to [[project-instahyre-assessment]] and any design copy generally.
